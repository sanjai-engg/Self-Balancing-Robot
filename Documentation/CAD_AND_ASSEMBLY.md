# CAD Design and Assembly

## Design tool

The mechanical design was created using **Autodesk Fusion**.

## CAD file included in this repository

| File | Format | Purpose |
|---|---|---|
| [Configuration 1.step](../CAD/Exports/Configuration%201.step) | STEP | Neutral 3D CAD exchange model |

The STEP export can be opened in many CAD applications. It does not retain the full parametric feature history of the native Fusion design.

## Mechanical information

The repository does not currently publish verified dimensions, chassis material, wheel dimensions, gear ratio, fastener specifications, or fabrication settings. These details are intentionally not inferred from the STEP filename or from the component descriptions.

## Assembly and physical views

Actual photographs of the assembled robot and a wiring diagram are the useful remaining visual documentation for this project. They should show the physical component placement, sensor orientation, motor connections, power distribution, and cable routing. The wiring diagram should be checked against the built robot rather than inferred only from firmware GPIO definitions.
